# Проектная работа «Сложно сосредоточиться»

Адаптивный одностраничный сайт о том, почему нам так сложно сконцентрироваться и как с этим справиться. Сайт поддерживает светлую и тёмную цветовые схемы и автоматически подстраивается под системную тему пользователя.

## Ссылки

- Репозиторий: [github.com/mhmsangare-ship-it/slozhno-sosredotochitsya-ad](https://github.com/mhmsangare-ship-it/slozhno-sosredotochitsya-ad)
- Сайт на GitHub Pages: [mhmsangare-ship-it.github.io/slozhno-sosredotochitsya-ad](https://mhmsangare-ship-it.github.io/slozhno-sosredotochitsya-ad/)

## Функциональность

- Три цветовые схемы: «День» (светлая), «Неон» (тёмная) и «Авто» (по настройкам системы).
- Адаптивная вёрстка по подходу Mobile first: мобильные устройства, планшеты (от 768px) и десктопы (от 1024px).
- «Резиновая» вёрстка без горизонтальной прокрутки между брейкпоинтами.
- Шапка и подвал на высоту экрана с минимально допустимой высотой.
- Фиксированное фоновое изображение, которое меняется вместе с темой.
- Галерея изображений с «ленивой» загрузкой.

## Технологии

- **HTML5**: семантическая разметка (`header`, `main`, `section`, `article`, `footer`, `nav`), один заголовок `h1` и многоуровневые заголовки.
- **CSS3**:
  - CSS-переменные для цветов, шрифтов, размеров и отступов;
  - Grid Layout для раскладки страницы и галереи;
  - медиазапросы в современном синтаксисе диапазонов (`width >= 768px`);
  - медиафича `prefers-color-scheme` и метатег `color-scheme`;
  - функция `clamp()` для адаптивного размера заголовков;
  - псевдоэлементы для декоративных уголков и индикатора REC;
  - состояния `:hover` и `:focus-visible` для ссылок и кнопок.
- **Шрифт**: IBM Plex Mono, подключён через `@font-face`.
- **JavaScript**: готовый скрипт переключения тем с сохранением выбора в `localStorage`.

## Структура проекта

```
├── fonts/       — шрифты IBM Plex Mono и fonts.css
├── images/      — фоновые изображения, иллюстрации галереи и фавиконки
├── scripts/     — script.js (переключение тем)
├── styles/
│   ├── globals.css   — глобальные стили и сброс отступов
│   ├── variables.css — CSS-переменные основной (тёмной) темы и адаптива
│   ├── style.css     — основные стили и медиазапросы
│   ├── dark.css      — принудительная тёмная тема
│   └── light.css     — светлая тема (по классу и по системной настройке)
└── index.html
```
